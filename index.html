How this works

This page sends the passenger details to my FastAPI app, which runs in a Docker container on my server. The app prepares the data the same way it was prepared for training, then asks the model for a prediction.

  • Model: Random Forest Classifier, about 82% accuracy on passengers it never saw during training
  • Training data: 891 passengers from Kaggle's Titanic dataset
  • Image: vfoster2docker/titanic-survival-api on Docker Hub
